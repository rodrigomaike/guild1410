# The Guild 1 Remake: Europa 1410 — Tradução PT-BR

Tradução amadora, não oficial e feita por fãs de **The Guild 1 Remake: Europa 1410** para **Português Brasileiro (PT-BR)**.

A tradução é focada nos textos do jogo e mantém as vozes originais.

## Instalação

Baixe os arquivos da tradução disponíveis neste repositório e coloque-os na pasta:

```text
SteamLibrary\steamapps\common\The Guild - Europa 1410\Europa1410\Content\Paks
```

Os arquivos da tradução devem ficar junto dos arquivos originais do jogo. Não é necessário substituir ou excluir nenhum arquivo original.

Depois, defina o idioma do jogo como `pt-BR`.

### Opções de inicialização da Steam

Na Steam, abra:

**Propriedades → Geral → Opções de inicialização**

Adicione:

```text
-Culture=pt-BR -Language=pt-BR -Locale=pt-BR
```

## Tradução

A tradução abrange os textos localizados do jogo, incluindo:

- Ações
- Eventos
- Construções
- Cidades
- Combate
- Itens
- Notificações
- Política
- Profissões
- Configurações
- Efeitos
- Títulos
- Características
- Trabalhadores
- Outros textos do jogo

Os **nomes dos NPCs não foram traduzidos**.

As vozes originais do jogo permanecem inalteradas.
